## 📌 Overview

Smart E-Commerce Platform is a full-stack online shopping application built with React, FastAPI, Django and MySQL.

The platform provides a modern customer shopping experience together with an administration backend for managing users, products and orders.

---

## ✨ Features

### 👤 Customer Features

- User registration and login
- Product browsing
- Product search
- Category filtering
- Shopping cart
- Quantity management
- Buy Now
- Checkout
- Order history
- Order tracking
- Notifications
- Responsive UI

### 🛠️ Admin Features

- User management
- Product management
- Product images
- Order management
- Order status management
- Administrative dashboard

### 💳 Payment

- Checkout workflow
- Payment status handling
- Order creation
- Stripe integration structure
